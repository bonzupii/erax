# UTF-8 demo corpus for erax, generated from canonical Unicode data.

# Regenerate with: python3 gen_demo_corpus.py
#
# Width model: one cell per extended grapheme cluster; two cells for a
# cluster whose base character is East Asian Wide or Fullwidth; zero cells
# for a base control character.
# The comment above each sample states the expected cluster count and cell
# width, computed from the canonical data. tests/demo_corpus.rs checks
# every sample against demo-expectations.json using the editor's own
# segmentation and width code.
#
# Sample lines start with the sentinel "» ".
